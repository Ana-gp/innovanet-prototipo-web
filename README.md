# Prototipo web de Innovanet Sistemas

Prototipo navegable del diseño de la nueva web corporativa de Innovanet Sistemas. Forma parte del Ejercicio 3 (diseño visual y prototipo) del curso PROCONSI / FGULEM.

> **Importante:** es un prototipo de diseño. Los textos, las imágenes y los artículos del Blog son **provisionales**. No es la web definitiva ni está preparada para publicarse.

## Cómo verlo

- Abre `index.html` en cualquier navegador, o usa el enlace de GitHub Pages si está activado.
- Funciona en escritorio y en móvil. No necesita instalación ni servidor.

## Qué se puede probar

- Navegación desde Inicio a las secciones principales.
- Desplegable de **Servicios** (escritorio) y menú móvil con acordeón.
- Las seis páginas de servicio; **Ciberseguridad** tiene sus fichas desplegables.
- **Hablemos** lleva a Contacto, con el formulario de ejemplo (no envía nada).
- **Blog**: listado y artículo de ejemplo.
- **Asistencia remota**: en el prototipo abre una ventana con los cuatro pasos y el aviso de seguridad (los mismos pasos están en la página de Asistencia técnica); el enlace de descarga está pendiente.

## Contenido

| Archivo | Qué es |

## Estado de la información

- **Confirmado por el cliente:** estructura de seis servicios, menú de cinco entradas, descarga directa de TeamViewer, Blog con un artículo en el lanzamiento, web solo en español.
- **Propuesta del consultor:** agrupación en «Privacidad y cumplimiento», FAQ como bloque dentro de Contacto, líneas de Consultoría IA.
- **Pendiente:** enlace de descarga de TeamViewer, variante y licencia de la tipografía Bauhaus (se usa Poppins como sustituto), textos legales y contenidos finales.
